# ZB Idea Manager

A mobile-first app where verified ZB staff post ideas, answer executive challenges and follow ideas from sketch to launch. Executives rank and approve the best ones.

- Live site: https://zb-idea-manager.vercel.app
- Documentation (features, diagrams, WhatsApp chatbot design): [docs/DOCUMENTATION.md](docs/DOCUMENTATION.md)

Run locally: `python -m http.server 8123`, then open http://localhost:8123/index.html
